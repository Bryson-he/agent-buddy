Meet Agent Buddy

A small character at the top of your screen that shows what your AI agents are doing, and asks you when one of them needs a yes or no.

  • See it at a glance. Working, finished, stuck or waiting for you, without opening the agent's window.
  • Answer from anywhere. Click the notch, press a shortcut, or use the Windows notification.
  • Stays on this PC. Nothing leaves your computer unless you switch on the tunnel for a cloud bot.
See it moveLook at the top of your screen. The last step asks a question: answer it on the notch.

Make it yours

Each switch saves as you change it. Everything here is also in Settings later.

Every agent gets its own colour. Once an agent has reported, you can change its colour in Settings.

Connect an agent

Pick what you use. You can connect more than one, and come back here from the tray menu.

Claude CodeShows each step and asks before risky commands
  1. Needs Node.js installed (the hooks are small Node scripts).
  2. Copy the hooks block and merge it into %USERPROFILE%\.claude\settings.json.
  3. Start a new Claude Code session. /hooks lists them.
or use "Let an AI do it"
CursorShows shell commands and edits, asks before risky commands
  1. Needs Node.js installed.
  2. Copy the hooks file and save it as %USERPROFILE%\.cursor\hooks.json (merge if you already have one).
  3. Restart Cursor.
or use "Let an AI do it"
A cloud bot (Grok Bot and similar)Bots that run on someone else's servers reach you through a secure tunnel
  1. Install cloudflared (winget install Cloudflare.cloudflared), then switch the tunnel on:
  2. In the bot's app, add a custom connector of type Remote HTTPS named agent-buddy:
  3. Give each bot the skill that tells it to report. Type the bot's name, then copy:

The tunnel address is random and changes after a restart unless you set up a fixed one. The README explains how. Treat the header value like a password.

Anything else that speaks MCPTwo tools: set_status and ask_user
  1. Add Agent Buddy as an MCP server in your agent's config.
  2. Tell the agent to call set_status as it works and ask_user before anything you would want to approve.
